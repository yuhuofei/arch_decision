# Architecture — Discovery

Run the canonical discovery phase.

## Mandatory Reading

Read:

- `AGENTS.md`
- `.sdd/CANONICAL.md`
- `.sdd/decision-trees/decision-protocol.md`
- `.sdd/workflows/new-project.md`

Then load only the relevant domain knowledge.

## Objective

Understand:

- project type
- users
- scale
- deployment environment
- data characteristics
- integration requirements
- security requirements
- compliance requirements
- operational constraints
- team constraints
- cost constraints
- explicit preferences

## Rules

Do not select a technology stack yet.

Do not infer missing facts as confirmed facts.

Mark unknown information explicitly.

Separate:

- hard constraints
- preferences
- assumptions
- unknowns

## Output

Update the project discovery artifact.

Report:

1. Known requirements
2. Unknowns
3. Assumptions
4. Constraints
5. Questions requiring human input

Do not implement code.
